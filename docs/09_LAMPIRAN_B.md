| Objective & metrik utama | **Objective**: Membangun model machine learning yang mampu mendeteksi serta mengklasifikasikan tingkat keparahan jalan berlubang dari citra secara akurat, sekaligus menentukan bobot urgensi perbaikan.<br>**Metrik Utama**:<br>- *Classification / Detection*: Macro F1-Score, Precision, Recall, serta *mean Average Precision*.<br>- *Inference Latency*: Waktu inferensi per frame/citra untuk memastikan kelayakan implementasi. |

| Rencana tiga model (baseline / advanced / deep learning) | 1. **Model 1 (Baseline - Classical ML / Feature Extractor)**: Ekstraksi fitur visual (Histogram of Oriented Gradients/HOG atau Color Histogram) yang diklasifikasikan menggunakan Support Vector Machine (SVM) atau Random Forest (pada cropped image patches).<br>2. **Model 2 (Advanced / Standard Deep Learning - Transfer Learning CNN)**: Arsitektur klasifikasi/deteksi standar seperti ResNet-50 atau MobileNetV3 yang di-fine-tune untuk mengenali wilayah lubang jalan.<br>3. **Model 3 (State-of-the-Art Deep Learning)**: YOLOv8 / YOLOv11 (nano/small variant) untuk lokalisasi objek terintegrasi secara end-to-end, menghasilkan koordinat bounding box guna estimasi luas kerusakan untuk pembobotan prioritas. |
